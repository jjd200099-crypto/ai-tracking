核心结论 / Thesis
  • $45B ARR 真实，且 5 月仍在 reaccelerate。Yipit panel 测算 ($44.3B Apr / $48.4B May) 与 CFO 披露 ($45B "imminently") 误差 <3%；5 月部分数据已超 4 月 18%，全月 run-rate 可能落在 $50-55B。
  • 这是一家 API 公司，不是 SaaS 公司。API（Cloud + OpenRouter + B2B Direct）占 ARR 87.2%；Consumer Subs 仅 12.8%。跟 OpenAI 50%+ ChatGPT 完全相反的路径。
  • Enterprise 已经是现在不是未来。Cloud API 占 reweighted ARR 从 25% (2024-11) 升至 48.5% (2026-05)；Consumer Subs 反向从 37% 缩到 13%；mix 翻转完成。

  • Opus 已超过 Sonnet 成为最大模型 (May 2026 新发现)。Opus tier $25M vs Sonnet $15M；token 量 12.5T vs 10.9T。Mix 在向更贵的 tier 升级 — 客单价上行。
  • NDR >500% 真实但 bimodal。Cohort 数据显示 2025-Q2/Q3 cohort 扩张 50-160x；2024 早期 cohort 只 5-25x。新客户 ramping 速度远超老客户。

Bear / Risk 数据点

  • − Cohort dispersion 大 — outlier 驱动平均，统计意义弱

使用本数据的 5 个 Caveat

  1. Coverage 仅 1.5%：Yipit 看不到 Anthropic 大量收入（私有合约、AWS rebate、co-sell deals）。Estimated ARR 是 coverage ratio 反推，依赖"看不见的部分"占比稳定的假设。
  2. Subs 的 ×25 reweight：calibrated to Anthropic 2025-Oct 披露的"80% enterprise"。若那条 disclosure 不准 / mix 已变，整个 ARR 拆分 mix 都要重算。
  3. Cloud API 仅看 Bedrock/Vertex/Foundry 公开计费：私有合约部分未计。
  4. Cohort panelist 数小：单点 outlier cohort (164x) 仅 21 panelists，统计意义弱方向性强。
  5. OR pre-2025-06 有 caching bias：早期 OR spend 略 overstated（Yipit 自己 footnote 提示）。
